BIRTHDAY WEBSITE — QUICK SETUP

1. Copy the entire happybirthdaytinamarie folder into the ROOT of your GitHub Pages website repository (the same level as your main index.html).
2. Replace letter.txt with your birthday message.
3. Add background.jpg (the JPG you want to repeat across the page).
4. Add birthday-video.mp4 (H.264 MP4 recommended).
5. Optional: add video-poster.jpg for the video thumbnail.
6. Optional: add animated GIFs named gif1.gif, gif2.gif, gif3.gif, gif4.gif, gif5.gif. Missing GIFs are automatically hidden.
7. Commit and push. Visit https://rydeck.com/happybirthdaytinamarie/ after GitHub Pages deploys.

Confetti is animated with built-in CSS and JavaScript, so you do not need a separate confetti GIF. It stays over the page and never blocks clicking the video.

NOTE: This URL is unlisted, NOT password-protected. Anyone with the link can view it. Avoid linking it from the main website if you want to keep it a surprise.

For large videos, GitHub has a 100 MB per-file limit in normal Git uploads. Compress your video for the web or use a separate video host if needed.
